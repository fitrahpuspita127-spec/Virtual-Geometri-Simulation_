# Virtual-Geometri-Simulation_
Virtual Geometri Simulation adalah media pembelajaran interaktif tentang teori VSEPR untuk SMA kelas X. Siswa menelusuri sendiri molekul NH₃ dan SO₃ lewat enam tahap berurutan: pengertian VSEPR, konfigurasi elektron, struktur Lewis, penentuan PEI dan PEB, model 3D yang bisa diputar dan diukur sudutnya, hingga rangkuman dan uji akhir berumpan balik.
